# Sidera desktop shortcuts

Super = Windows key. Edit conf.d/shortcuts.lua to change bindings.

- Super alone: Sidera launcher
- Super+Z: terminal; Super+E: files; Super+B: browser
- Alt+S: Sidera settings; Alt+C: dashboard; Alt+N: notifications
- Alt+D: utilities; Alt+P: power menu; Alt+Q: reload Hyprland
- Super+L: Sidera lock
- Super+W / Super+Shift+W: next / previous wallpaper through Sidera
- Super+Q: close; Super+M: maximize; Super+Alt+V: floating
- Super+J: split direction; Super+Shift+P: pseudotiling
- Super+Arrow: focus; Super+Shift+Arrow: swap; Super+Alt+Arrow: move
- Super+1–9,0: workspace; add Shift to move a window
- Super+S: scratchpad; Super+Shift+S: move to scratchpad
- Super+H / Super+Shift+H: minimize / restore
- Super+mouse wheel: change workspace
- Super+left/right drag: move/resize window
- Print / Insert: region screenshot with Swappy
- F1: mic mute; F2/F3: volume; F4: speaker mute; F6/F7: brightness
- Dedicated media, volume and brightness keys retain their functions
- Super+Alt+S/R/X: suspend/reboot/shutdown
- Super+Alt+O or Super+Shift+M: logout through UWSM

Hyprshell-only panel, monitor, Hyprview and settings-backend shortcuts were removed.
Personal monitor, appearance, workspace and application rules are now in conf.d.
Sidera preferences use ~/.config/caelestia/shell.json and its Nexus settings UI.
