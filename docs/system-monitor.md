# Hyprmonitor

Hyprmonitor is maintained as an independent application, outside this checkout.
Hyprshell does not build, package, install, configure or bind shortcuts for it.
Updates preserve an existing `~/.local/bin/hyprmonitor` and application launcher;
preferences belong to `~/.config/hyprmonitor/config.toml`.

Launch it from the application menu or run `hyprmonitor --settings`. Optional
compositor shortcuts and layer rules can be configured by the app user.
