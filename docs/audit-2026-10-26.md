# Daily-driver audit — 2026-10-26

Completed 2026-10-27 after deployment verification.

This audit checked installed dependencies, the running shell's readable logs,
the repository and matching installed files, desktop helper failure paths,
media scheduling, panel geometry, Settings workflows, installer planning,
configuration recovery, and the existing Python and native Qt checks.

## Fixes

| Finding | Result |
| --- | --- |
| Screenshot pipelines started Swappy even when region selection was cancelled or capture failed. | A shared helper finishes a successful, nonempty capture before opening the editor. Temporary images are private and removed on exit. Print/Insert retain frozen region capture; Shift+Print/Insert retain full-screen capture. Systems without the optional freeze tools fall back to normal region selection. |
| The packaged Swappy desktop entry has malformed command escaping. | An installer-managed user entry invokes the shared helper directly, retaining the existing name, translations, icon, visibility and MIME types. Opening an existing image passes its filename literally. GIO confirms this override is selected; Quickshell still logs warnings while parsing the shadowed system entry. |
| A queued spectrum peak could survive a later return to the already displayed silent frame. | Each valid incoming frame supersedes the queued frame, including silence. Invalid frames remain ignored and capture shutdown discards pending data. |
| Long music titles woke a timer every 67 ms although characters change only every 300 ms. | A single-shot timer schedules the next character boundary and opening pause. Unicode handling, playback detection, the silence grace period, and idle shutdown are preserved. |
| Compact side-panel spectrum padding left less than a pixel for each bar. | The spectrum uses proportional width within the circular pill; all five bars remain visible. |
| Hiding an icon while changing panel orientation caused a QML `y` binding-loop warning. | Invisible glyphs skip baseline positioning. Existing geometry checks cover the orientation transition. |
| Wallpaper cycling mishandled octal-looking, overflowing or stale cache values, newline filenames, failed transitions and simultaneous shortcut presses. | Decimal/bounded index handling, null-delimited filenames, serialized transitions, daemon-readiness checks and success-only state updates preserve the chosen position. Previous from an unset position selects the final wallpaper. |
| New package dependencies lacked meaningful installer-preview categories. | Screenshot/freeze helpers, DNS/network tools and Rust build tools are assigned to their existing subsystems. No package installation is performed by this change. |

## Regression coverage repaired

The media activity and projector fixtures had been deleted by earlier live-config
syncs while their Python tests still referenced them. Both are restored to the
checkout and installed payload so a later sync retains them.

Several tests still expected the dock/taskbar and pin menus deliberately removed
in `576ac77`, or the Settings welcome screen replaced by the home view in
`551c19b`. Tests now exercise the current launcher, focused-output routing and
guide completion through Settings → Help. These changes do not reintroduce the
removed features.

Panel checks now measure rendered glyph ink rather than the internal 128 px
outline font, test the current inset pill surfaces and pointed menu stems, and
show Settings categories before checking their layout. The recovery fixture
specifies the saved height instead of assuming the personal default stays 32 px.
Menu tests use the panel's `shown` state; its mapped surface deliberately remains
visible for quick reopening.

Quickshell suppresses debug messages by default in this environment. Tests that
use `console.log` completion markers need `QT_LOGGING_RULES=qml.debug=true`;
missing markers alone are not evidence that the UI failed.

## Performance evidence

An isolated native Qt comparison ran the old and new title schedulers together
for six seconds with the same long title. The old timer fired **89 times** and
the new timer **13 times**, about **85% fewer wakeups in that sample**. Both stop
when playback stops. The scrolling cadence remains one character per 300 ms.
This measures that scheduler, not whole-desktop CPU use, memory or frame times.

## Remaining measurement and hardware limits

Native dependencies and everyday applications are installed. Settings already
provides display rollback, input controls, audio devices and streams, network
profiles, Bluetooth, notifications, locking/power, backup/recovery, clipboard
history and application defaults. This audit found reliability and integration
gaps rather than a reason to add another resident service.

The agent session cannot connect to the host compositor, system/user D-Bus or
audio sockets and cannot see host process resource usage. Lock/unlock,
suspend/resume, physical display changes, audio/Bluetooth operation and portal
screen sharing therefore still need acceptance testing from the real session.
No sudo, system package changes or service reconfiguration were needed.

The upstream Swappy warning persists because Quickshell parses the root-owned
package entry as well as the corrected user override. Fixing that package file
requires a system-level change or package update; the selected user launcher is
already corrected. The audit does not claim that this warning disappeared.

Two further optimization candidates need desktop measurements: the wallpaper
watcher launches a query every two seconds, and connected Wi-Fi checks use a
bounded interface-specific probe every 30 seconds. Event-driven alternatives
must preserve external wallpaper changes and per-interface connectivity
semantics. This audit leaves those behaviors intact rather than claiming an
unmeasured improvement or reducing their functionality.
