# Shell icon font

`GoMonoNerdFont-Regular.ttf` is the unmodified Nerd Fonts 3.5.1 GoMono
regular font, copied from Arch's `ttf-go-nerd 3.5.1-2` package. It supplies
the `GoMono Nerd Font` family used by shell icons on both distributions.
It is installed locally, including the license notices, without downloading
files or replacing system fonts. Bold and italic desktop text uses the
distribution's other font packages.

Upstream: https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/Go-Mono

SHA-256: `383bab477bbb91186cb8961c490c9f45538d0540985c3eadccbcd4af16f7c629`

The original Go font license is in `LICENSE-Go.txt`; Nerd Fonts' license
notices are in `LICENSE-Nerd-Fonts.txt`.
